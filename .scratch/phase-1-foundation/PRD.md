# PRD — 阶段一:基础素材库

> Parent for issues under `.scratch/phase-1-foundation/issues/`.
> 需求源自 PRD V1.0 §21.1,经开发前设计讨论(ADR-0001~0006)裁剪后形成本阶段范围。

## 阶段一目标

搭建可独立 demo 的基础素材库闭环:单管理员上传 PPTX → Open XML 解析 + LibreOffice 渲染 → 文件/页面浏览 → 关键词全文搜索 → 下载/复制复用,全程任务进度可见,支持基础标签与软删除。

## 范围内(MVP)

- 账号:单管理员登录/改密/登出
- 上传:PPTX 手动上传、校验、SHA-256 去重、版本记录、任务进度
- 解析:Open XML 原生文本与结构提取(真值)
- 渲染:LibreOffice 转 PDF / PNG / 缩略图
- 浏览:文件列表、文件详情、页面卡片、详情抽屉、页面浏览器
- 检索:关键词全文搜索(应用层 jieba,默认仅当前版本)
- 复用:下载页面 PNG、复制页面文字、下载源 PPTX
- 运维:任务中心(阶段进度 + 失败重试)、基础标签、收藏、软删除回收站

## 范围外(明确推迟)

- **MinerU 增强解析** → 阶段二(ADR-0006:阶段一无模型配置中心,MinerU 强依赖模型层)
- **视觉模型分析 + AI 标签** → 阶段二
- **pgvector 语义检索 + RRF 融合** → 阶段二(ADR-0003:评测集与融合在阶段二)
- **版本链与页面变化匹配** → 阶段三
- **单页 PPTX 导出** → 阶段三(ADR-0002:关系图遍历 + 复制或拒绝)
- 多用户、SSO、NAS 自动同步、以图搜图、元素级拆解、PPT 组装
