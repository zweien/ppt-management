# 08 — 复用闭环:下载 PNG / 复制文字 / 下载源 PPTX

## Parent

阶段一 MVP(`.scratch/phase-1-foundation/`)。

## What to build

一条复用 vertical slice:在页面详情,用户能下载页面 PNG、复制页面文字、下载该页面所属 Presentation 的源 PPTX。这是 PRD §6.3 的三种复用方式中,阶段一可完整交付的部分。

注意范围裁剪(关键):

- **下载页面 PNG**:直接读取 #05 已生成的高清预览图 ✅ 阶段一可做。
- **复制页面文字**:组合标题、正文、备注(阶段一无 MinerU 文本)✅ 阶段一可做。
- **下载源 PPTX**:下载该页面所属 Version 的**整份**源 PPTX ✅ 阶段一可做。
- **导出单页 PPTX**:**阶段三**才做(ADR-0002 的关系图遍历 + 复制或拒绝)。本 slice **不**实现单页导出,但 UI 可保留入口占位(置灰 + "阶段三支持")。

端到端穿过:API(下载/导出端点,签名 URL 或后端流式)、UI(详情操作区按钮)、对象存储(MinIO 读)、test。

约束(遵守 PRD §6.3、§14.3):

- **下载访问控制**:通过短期签名 URL 或后端流式返回,**不**直接暴露 MinIO 内部地址与永久公开链接(§14.3)。
- **复制文字**:组合 native_text + notes_text(+ 标题),阶段一无 MinerU 文本。

## Acceptance criteria

- [ ] 页面详情操作区有「下载图片」「复制文字」「下载源 PPTX」三个按钮(§5.3 操作区)
- [ ] 下载图片:返回该页高清 PNG(#05 产物)
- [ ] 复制文字:组合标题 + 正文 + 备注,可复制到剪贴板
- [ ] 下载源 PPTX:返回该页面所属 Version 的整份源 PPTX
- [ ] 下载通过签名 URL 或后端流式,**不**暴露 MinIO 内部地址/永久公开链接(§14.3)
- [ ] 「导出单页 PPTX」入口存在但置灰,提示阶段三支持
- [ ] 全部需登录态
