# 06 — 页面卡片 + 文件/页面浏览 UI

## Parent

阶段一 MVP(`.scratch/phase-1-foundation/`)。

## What to build

一条浏览 vertical slice:用户能在文件管理页看到已上传的 Presentation 列表,进入文件详情看到所有 Slide 页面卡片(缩略图 + 页码 + 标题 + 源文件 + 版本),点击卡片在右侧抽屉打开页面详情(高清预览 + 基本信息 + 原始文字 + 所在文件)。

这是把 #04(文本)和 #05(预览图)的产物首次呈现给用户的 UI 闭环。**依赖 #04 和 #05 都完成**——卡片要同时有文本与缩略图。

端到端穿过:API(presentations / slides / versions 查询)、UI(文件列表 / 文件详情 / 页面浏览器 / 详情抽屉)、test。

覆盖 PRD:§5.3 页面详情、§5.4 文件详情与页面浏览器、SL-01、§14.1 presentations/slides 接口。

注意范围裁剪:

- **详情抽屉的 tab**:本 slice 实现「基本信息」「原始文字」「所在文件」三个 tab;「AI 摘要」「MinerU 解析」「标签」「版本信息」tab 占位(阶段二/三填充,见 CONTEXT.md 数据优先级)。
- **批量操作**:本 slice 只做单页查看;批量收藏/加标签/下载(§5.4)留给 #10 与 #08。
- **页面浏览器**:支持网格 + 列表切换、跳转页码(§5.4)。

## Acceptance criteria

- [ ] 文件管理页列出所有 Presentation(文件名、上传时间、页数、解析状态)
- [ ] 文件详情页展示当前 Version 的所有 Slide 页面卡片网格
- [ ] 每张卡片显示缩略图、页码、标题、源文件、版本
- [ ] 点击卡片右侧抽屉打开详情,含高清预览图(可缩放)、基本信息、原始文字、所在文件
- [ ] 页面浏览器支持网格/列表切换 + 页码跳转
- [ ] 上一页/下一页导航、当前页码/总页数显示(§5.3)
- [ ] 详情 tab:「基本信息」「原始文字」「所在文件」可用;其余 tab 占位不报错
- [ ] 全部需登录态;无数据时空状态有引导(提示去上传)

- 05 — LibreOffice 渲染(卡片要展示缩略图、详情要展示高清预览)
