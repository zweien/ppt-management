## Agent skills

### Issue tracker

Issues 和 PRDs 作为 markdown 文件存放在本 repo 的 `.scratch/` 下（local-markdown 约定）。See `docs/agents/issue-tracker.md`.

### Triage labels

使用五个 canonical role 字符串原样作为 `Status:` 值（needs-triage / needs-info / ready-for-agent / ready-for-human / wontfix）。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目录一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
